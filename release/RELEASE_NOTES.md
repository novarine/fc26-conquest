# FC26 Conquest 1.0.1

## Highlights
- Initial Windows desktop release
- Local campaign progression and conquest flow
- Seeded teams, regions, and player data
- Battle resolution and frontier capture based on the in-game rules
- Local save/load support for a single-player campaign

## Improvements
- polished Windows installer flow
- improved update-check and manifest handling
- better release packaging setup for desktop distribution

## Notes
- This is a local desktop MVP build intended for evaluation and setup testing.
- A valid public code-signing certificate is required before distributing the installer outside a trusted local environment.
